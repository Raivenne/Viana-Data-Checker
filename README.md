# Viana Data Checker

Automation script using Selenium to check missing data in Viana X-Ray portal.

## How to Use

1. Run the script
2. Log in manually
3. Navigate to:
   X-Ray → Audience Measurement → Explore
4. Press ENTER in terminal

## Features

- Iterates through sites and zones
- Applies filters automatically
- Detects "no data" conditions
- Generates report

## Requirements

- Python 3.x
- Selenium
- ChromeDriver

## Notes

- Requires manual login
- Requires access to QIC network
